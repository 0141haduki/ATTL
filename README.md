# ATTL Web v0.2

ここまでの仕様を反映した操作確認版です。

主な更新:
- トップを「今日を含む7日間」に変更
- 日付タップで1日編集
- PLANは30分単位のスライド作成
- 科目記号を選択、長押しで科目名表示
- 科目設定で「理論のみ / 理論・計算」
- PLANブロックをタップで詳細編集
- PLANブロック長押しで30分単位移動
- 左右端ドラッグで30分単位伸縮
- 学習予定同士の時間重複禁止
- 予定終了時刻経過でDOへ自動実績化
- PLAN詳細から「実績へ移行」
- DOは詳細画面で1分単位編集
- 教材・勉強内容は任意
- 自宅外学習は薄黄色
- 睡眠自動表示
- 月間勤務カレンダー、複数日選択、勤務セット一括反映

起動:
1. ZIPを展開
2. VS Codeで ATTL_web_v0_2 フォルダを開く
3. index.htmlを開く
4. Live Serverの Go Live を押す

保存はブラウザのlocalStorageです。


## v0.2.1 修正
- 一部ブラウザで JavaScript 全体が停止する可能性がある `crypto.randomUUID()` 依存を削除。
- 読み込みエラーが起きた場合、画面上部に赤いエラーメッセージを表示するように変更。


## v0.2.2 修正
- 起動直後に `clone` を初期化前に参照して JavaScript が停止する不具合を修正。
- これによりナビゲーションボタン、7日間表示、設定画面などのイベント登録が正常に進むよう修正。


## v0.3
- 7日間画面に0〜23時の1時間単位ヘッダーを追加。縦スクロール時に上部へ追従。
- 学習ブロックは科目記号1個＋四角形に簡素化。横棒と2個目の図形を廃止。
- タイムライン上の予定/実績ブロックをクリック・タップして詳細編集。
- 予定詳細には既存の削除ボタンを維持。
- 30分ブロックの詳細が読めない問題に対し、1日編集画面の下に「予定詳細一覧」を追加。タイムラインは省スペース、一覧では教材・範囲を全文表示。
- 勤務セットに消去ボタンを追加。
- 睡眠時間を薄い黒（半透明グレー）で表示。
- 「週参照（月〜日）」を追加。前週・今週・次週で1週間単位に移動し、PLAN / DOを参照。
- 過去週の日付から1日編集へ移動可能。


## v0.4
- 実績ブロックを1分単位で編集。
- 「＋予定外実績」からPLANにない学習をDOへ直接追加。
- 予定終了時刻の自動実績化と「実績へ移行」を維持。
- 実績詳細一覧を追加。

## v0.5
- 「昨日の予定をコピー」を追加。
- PLAN詳細から「複製」を追加。直後の空き時間へ同じ長さで複製。
- 教材欄に、その科目で過去に使った教材候補を自動表示。

## v0.6
- 1日ごとのPLAN / DO差分を自動表示。
- 総時間差、科目別時間差、開始時刻のズレ、学習時間差、未着手、予定外実績を表示。
- 分析用データは内部で保持し、月間画面は追加しない。

## v0.7
- CHECK / ADJUSTに任意のワンタップ原因タグを追加。
- 計画過大 / 仕事 / 睡眠 / 着手できず / 科目回避 / 体調 / その他。
- 複数選択可。自由記述メモは任意のまま維持。
- 勤務予定カレンダーで複数日を選択し、「選択日の勤務を空にする」で勤務予定を一括消去可能。

### データについて
localStorageのキーは旧版と共通のままにしているため、同じブラウザ・同じLive Serverのオリジンで開く場合、v0.2/v0.3の保存データを引き継げます。


## v0.7.1
- 7日間・1日編集のタイムライン上では、学習ブロック内に科目記号だけを表示。
- 教材名・ページ数・勉強内容はタイムライン上では非表示。
- 30分ブロックでも科目記号を四角形の中央に配置。
- ブロックをクリック/タップすると従来どおり詳細編集を開く。
- 1日編集下部の予定詳細・実績詳細一覧では教材・範囲を確認可能。
- 数字・英字・全角コロン・長音/ダッシュ類・全角チルダ・全角スペースを、保存時/フォーカス離脱時に半角へ自動正規化。

## v0.8 復習基盤
- PLAN/DOブロックに「通常学習 / 復習」の属性を追加。
- 1日画面に復習PLAN・復習DO・実績内復習比率を表示。
- 固定1/3/7/14/28日方式や未消化復習の自動繰越は実装しない設計。
- 「GPT復習用テキストをコピー」を追加。理論は検索練習型、計算は再演習を前提とする指示を生成。
- 既存データは studyKind がない場合「通常学習」として扱うため互換性を維持。
